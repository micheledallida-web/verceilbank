Putting it in place

  1. Namecheap Private Email — Settings → Identities → your identity → Signature, switch the box to HTML, paste.
  2. Apple Mail — Settings → Signatures, paste, then untick “Always match my default message font”.
  3. Gmail — Settings → General → Signature, paste. Gmail keeps the layout but adds its own spacing above it.
  4. Outlook — File → Options → Mail → Signatures, paste. Outlook renders the table; it ignores rounded corners, which is why this card has none.

The logo is loaded from verceilbank.com/logo-mark.png, so it appears once the recipient allows images — most clients hold remote images until asked. Everything that matters is text, so the signature still reads with images switched off.
